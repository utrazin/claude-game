# Rule Set: Chibi Style

Visual and proportion guide for chibi characters, creatures, and props.

## Metric Proportions
| Subject Type | Dominant Feature | Proportion Guidance |
|---|---|---|
| Humanoid Character | Head | Head height = 35% - 45% of total height (2.2 to 2.8 heads tall total). |
| Quadruped / Creature | Head / Eyes | Head height = 40% - 50% of body length; shortened legs (50% standard length). |
| Props / Items | Focal Part | Exaggerate functional feature by 1.5x - 2.0x (e.g. blade guard, hammer head). |

## Geometric Rules
- Simplify secondary volumes: merge minor contours into unified low-poly masses.
- Minimum feature size: avoid micro-cubes or polygon spans < 1.0 unit unless detailing eyes/face.
- Bilateral symmetry mandatory unless asymmetric wear/damage is requested.
- Never override technical manifold or integer dimension rules for styling.
