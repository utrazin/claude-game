# Structure Presets: Macro Shapes of a Game

> **How to use:** pick the preset closest to the concept, then adapt. Each preset lists the typical scenes and screens, so the Experience Map starts from a realistic inventory instead of one arena plus a menu. Counts and numbers are illustrative.

---

## 1. Hub + Run (Expedition Roguelite)

* **Macro loop:** prepare at a hub -> run through challenge spaces -> return with resources -> convert resources into power or options -> repeat.
* **Typical scenes:** hub (walkable, with stations), 2-4 run spaces with different layouts, a boss or finale space.
* **Typical screens:** loadout or build screen, crafting/cooking/upgrade screen, run map or route choice, run summary, collection or codex.
* **Verbs that must exist in different places:** prepare (hub), fight or navigate (run), choose a route or risk (map), convert (station screen).
* **Coherence checks:** every resource gathered in a run is used at a station. Every station output changes the next run in a way the player can see.
* **Minimum differentiation:** hub and run use different camera feel, pace and verbs.

## 2. World + Levels (Level-Based)

* **Macro loop:** pick a level on a map -> play it -> earn stars or unlocks -> open the next levels.
* **Typical scenes:** level map, 3+ level themes, optional boss levels.
* **Typical screens:** level select with progress, level intro, results, shop or tool unlock.
* **Coherence checks:** each theme introduces one new rule or element. Results feed an unlock the player wants.

## 3. Scene Adventure (Explore + Interact)

* **Macro loop:** explore a space -> find items or characters -> solve a blocker -> unlock a new space.
* **Typical scenes:** 3+ connected locations, each with its own props and purpose.
* **Typical screens:** inventory (only if items combine or are used), dialogue, journal or map.
* **Coherence checks:** every item has a use. Every location has something that exists only there.

## 4. Management with Screens (Sim / Tycoon / Idle)

* **Macro loop:** produce -> spend -> expand -> unlock new production -> repeat.
* **Typical scenes:** main workspace or world view (visible state), optional special event spaces.
* **Typical screens:** shop or upgrades, production detail, stats, milestone or prestige screen.
* **Coherence checks:** each upgrade changes a visible element of the workspace. Each milestone introduces a new resource or mechanic, not only bigger numbers.

## 5. Arena Survival (Single Space)

* **Macro loop:** survive escalating waves -> choose upgrades between waves -> reach a score or end state.
* **Typical scenes:** one arena. Add variants (arena themes or modifiers) when the scope tier is above `prototype`.
* **Typical screens:** upgrade choice (qualitative options), run summary, unlock or loadout screen.
* **Coherence checks:** upgrade choices change how the player plays, not only the numbers. Arena variants change positioning decisions.

## 6. Puzzle Progression

* **Macro loop:** learn a rule -> solve levels that use it -> combine with another rule -> repeat.
* **Typical scenes:** puzzle board per level, optional themed worlds.
* **Typical screens:** level select, undo/reset controls inline, results.
* **Coherence checks:** each level group isolates one rule before combining. Reset and undo are instant.

---

## Mixing Presets

Combine macro shapes when the concept needs it (for example, Hub + Run with a Management station). Keep each scene's verbs distinct, and list every scene and screen in the Experience Map.
